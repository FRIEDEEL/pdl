# Growing flowcharts

FlowNode, Decision, and Terminal are editable parametric components. Their
outgoing graph expands to core Entity/Group objects during capture. Label and
edge edits affect subsequent captures. Numerical Connection endpoints are fixed
when constructed. See the [guide](../flowcharts.md).
