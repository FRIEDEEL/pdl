# pdl tutorial — working notes

The API is provisional. These chapters prioritize readable examples and explicit
behavior over polished transitions. Read by topic; the seven parts provide an order.
Examples use the current API only.

Each example links its source and actual output. Run from the repository root with
`uv run python -m examples.tutorial.render_all` to generate tutorial images.
TeX examples require XeLaTeX and dvisvgm; see the text/formula chapter.
