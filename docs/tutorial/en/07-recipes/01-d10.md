## The shape

The example helper constructs a pentagonal trapezohedron with 12 shared vertices,
20 edges and 10 planar kite faces. Every face is an ordered loop with implicit
closure. The small alternating ring heights make the four vertices of each kite
coplanar. This is example geometry, not a dedicated D10 library constructor.

## Artwork in each face's chart

`with_face_artwork(index, graphic)` returns a new Polyhedron, replacing the artwork
at that input face index. A face chart is centered on the average of its vertices,
with unit basis vectors and local up toward world +z projected into the face.
Horizontal faces use their first edge as the local x direction. Positive loop
winding gives the outward normal; input indices remain stable after painter sorting.

Node centers the number with deferred font measurement. Its box is invisible and
its text has an explicit white fill. Coordinates and artwork dimensions are local
millimeters; text size remains TeX points. The illustration uses 1-10 as convenient
labels, not a claim about standard opposite-face numbering or physical die fairness.

Projection groups each face with its artwork before sorting, so later faces cover
both the earlier face and its number. Back-facing artwork is retained and mirrored; edge-on artwork may collapse.
Artwork is not shaded or clipped automatically; keep it inside its face. Number
glyphs retain native text output and undergo the complete plane affine deformation.
If the solid is transformed, existing artwork placement is transported with it.

## The legend stays in 2D

`projected.face_center(0, 0)` supplies the first face's projected vertex average.
It does not check whether that face is visible. The leader and legend are created
after projection and grouped with it; moving the complete Group preserves their
relationship. Font/layout evaluation happens only when the resulting 2D drawing
is queried or rendered.

The [larger D10 example](../../../../examples/spatial/d10.py) shows opposite views,
uses underlines to distinguish 6 and 9, and lets you inspect all ten numbers.

![Opposite D10 views](../../../../examples/output/spatial/d10.svg)

Try changing one number's color or applying a 2D rotation through the `transform`
argument of `with_face_artwork`. This artwork example explicitly selects
`visibility="centroid"`; its depth sorting remains approximate. BSP for scenes
without artwork is explained in [related chapter](../05-spatial/05-visibility.md);
face intersections, cyclic occlusion, artwork clipping and perspective are outside
this chapter's scope. No half-space construction or surface-splitting API is added.
