# 7.1 Number the faces of a D10

The D10 example parameterizes a pentagonal trapezohedron with indexed kite faces, attaches number Entities in face charts, then projects the solid. Face indices and source-point queries remain stable across paint sorting.

Plane deformation determines whether number glyphs remain native or become paths. Face artwork is not automatically lit or clipped; this recipe uses centroid ordering explicitly. Build a separate 2D legend from a queried face center, then Group it with the projected result. The source also shows an independent opposite view.
