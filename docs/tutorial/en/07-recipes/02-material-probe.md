# 7.2 Material and probe

The larger example builds the illustration as named parts: rear material wall,
explicit planar lower cross-section, probe, then 2D leader and label. The last
panel changes the probe in 3D before projection; the pale first panel preserves
the material background for comparison.

![Material background, assembled cutaway and repositioned probe](../../../../examples/output/spatial/material_probe.svg)

[Complete source](../../../../examples/spatial/material_probe.py) — run
`uv run python -m examples.spatial.material_probe` for SVG, TikZ and PDF.
Edit `make_material`, `make_probe` and `make_cutaway` to change the geometry and
paint order. The floor is deliberately authored with Plane3D; it is not a cap
generated by CylinderSurface or the result of a solid boolean operation.

This recipe does not automatically hide a probe segment behind material. Split
that segment into separate front/back layers when necessary, or use one supported
BSP scene when physical polygon visibility is required. Recheck the intended
paint order when changing camera direction. This workflow is for editable vector
illustrations, with no shared depth buffer or automatic solid sectioning.
