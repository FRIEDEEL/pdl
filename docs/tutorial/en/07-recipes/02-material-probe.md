# 7.2 Material and probe

Describe material and probe components parametrically, project each component explicitly, and combine the resulting 2D Entities with annotation. Keep the unmodified material or alternate camera views beside the final assembly for comparison.

Separate component projections provide deliberate illustration coverage. Use one supported combined visibility scene when physical inter-object depth ordering is required. Parameters, relative construction, and reusable Python component functions remain in the example library.
