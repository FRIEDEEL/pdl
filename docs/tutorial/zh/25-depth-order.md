## 自动顺序与透明度

不带面内图案的纯多面体场景默认采用 BSP，包括透明面。本例的自由 Plane3D 图案
使用 `visibility="centroid"` 明确选择近似排序，依照 `depth_point` 参考点的相机轴向深度，
不是到相机的欧氏距离；默认参考点是局部 `(0, 0)`。选择合适的中心有助于普通图表，
但不能解决一般遮挡。近似模式中面内图案随完整面一起排序。

`Polyhedron.opacity` 默认 1，范围 `[0, 1]`，分别作用于面的填充和描边。
这是逐面／片段合成，不是折射玻璃或整个实体的隔离透明度。面内图案保留自身透明度，
需要透明数字时应单独设样式。背面图案从后方看会镜像，侧立图案可能退化；
后画的不透明面自然覆盖前面的内容。自由平面图案沿用 `Style(opacity=...)`。

## 手动顺序

`sort_faces=False` 保留对象顺序及多面体原始面顺序，不切分。本例故意先列出近橙板、
再列出远蓝板，自动中心排序将其纠正，手动模式则保留蓝板在上的结果。

`projected.reordered(order)` 接收包含全部当前子项索引的排列，索引 0 最先画。
手动模式中每项是完整面及图案或一个其他对象；BSP 结果则可能包含多个片段，
`source_faces` 保留源面对应关系并随重排更新。重排后标记为 manual。
顶点和面中心查询不改变原始索引。示例中的 `restored` 展示两项对调。

## 边界

近似中心排序即使面对互不相交的面也可能出错；完整面的手动重排不能解决循环。
BSP 对支持的面片通过切分解决这些情况，见[相交面与可见性](26-visibility.md)。
独立场景仍按普通 Canvas／Layer 顺序叠放。球和圆柱仅支持正交投影，曲面、自由平面
图案和面内图案仍需近似或手动模式。
