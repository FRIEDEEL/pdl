## 自动排序

同一个 Scene3D 内，每个面按顶点平均位置沿相机轴线的深度，从远到近绘制；深度相同则保留
输入顺序。面内图案与所属面一起排序，图案内部保持自己的二维绘制顺序。Plane3D 放置按
`depth_point` 排序，默认是局部 `(0, 0)`；图案偏离原点时应指定合适的局部中心。
不比较欧氏距离、二维投影重叠区域或逐条视线的交点。

`Polyhedron.opacity` 默认为 1，范围是 `[0, 1]`，独立应用到每个面的填充和描边。
这是普通透明合成，不模拟玻璃、折射，也不是整个物体隔离合成后的透明度。
面内图案保留自己的透明度；希望数字也透明时，需要显式设置图案样式。
背面图案保留，从背后看会镜像；侧立图案可能退化。不透明面在后绘制时自然盖住它。
平面图案使用普通 `Style(opacity=...)`。

## 手动顺序

`sort_faces=False` 保留对象输入顺序，每个多面体内部再按 faces 的输入顺序绘制。
示例故意先提供较近的橙色面、再提供较远的蓝色面。左侧自动排序改正这个顺序；右侧手动
模式保留输入顺序，因此蓝色画在上面。

需要全局指定顺序时，可以用 `projected.reordered(order)`。元组必须包含全部当前 child
索引，且每个恰好出现一次；索引 0 对应的对象先绘制。每个 child 是完整面及其图案，
或一个其他场景物件。先用 `sort_faces=False` 投影，就能让索引对应对象／面的输入顺序。
重排后，顶点和面中心查询仍使用原始源索引。源码中的 restored 演示将两个手动绘制项
反序，不修改几何。

## 已知限制

假定面之间不相交。即使如此，深度区间重叠时，面中心排序仍可能错误；循环遮挡则不存在
正确的完整面顺序，手动重排也无法解决。不检测循环，不切分面，不做局部裁剪或精确透明
遮挡求解。不同投影场景之间按普通 Canvas／Layer 顺序绘制。
球和圆柱仍只支持正交投影，按整个对象排序；本章多边形面的背面和透明度规则不扩展它们的 API。

试着把橙色面的透明度从 0.55 改为 1，再交换手动对象顺序：几何没变，重叠效果会随绘制顺序改变。
