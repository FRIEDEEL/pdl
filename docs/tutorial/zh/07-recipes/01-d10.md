# 7.1 为 D10 各面添加数字

D10 示例以索引风筝形面参数化五角偏方面体，在面的坐标图中放置数字实体，再投影形体。绘制排序不改变面索引和源位置查询。

平面变形决定字形保留原生表达还是转路径。面图案不会自动受光或裁剪，本例显式使用 centroid。可根据面中心查询建立独立 2D 图例，再与投影结果组合；源码还给出独立的反向视图。
